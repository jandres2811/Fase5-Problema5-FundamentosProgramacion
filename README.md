## Problema seleccionado
Problema 5: Cálculo de horas semanales y clasificación de jornada laboral.

## Descripción
Este programa permite registrar las horas trabajadas por cinco trabajadores durante una semana laboral. Posteriormente calcula el total de horas trabajadas y clasifica la jornada laboral como "Sobretiempo" cuando supera las 40 horas o "Horario estándar" cuando es igual o inferior a este valor.
